Overview

This project implemented a manipulation pipeline for a redundant 7-DOF Franka Emika Panda robot arm, connecting robot kinematics, motion planning, trajectory generation, and perception-based manipulation.

Key Contributions

  • Implemented forward kinematics, inverse kinematics, differential kinematics, and trajectory generation in Python.
  • Developed Jacobian pseudoinverse and Jacobian transpose inverse kinematics with null-space optimization.
  • Implemented RRT and Artificial Potential Field planners with collision checking.
  • Integrated vision-based localization with ROS/RViz for autonomous pick-and-place tasks.

Methods / System

  • Algorithms: FK/IK, Jacobian-based control, null-space optimization, RRT, APF, Cartesian trajectory generation.
  • Tasks: grasping, transporting, and stacking square blocks.
  • Tools: Python, ROS/RViz, simulation and physical robot evaluation.

Results and Next Steps

  • Completed autonomous manipulation experiments with block picking and stacking.
  • Generated a 45-page IEEE-style technical report documenting implementation and evaluation.
