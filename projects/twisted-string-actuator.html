Overview

This project focuses on building an experimental platform for characterizing twisted-string actuators under variable payload and mechanical constraint conditions. The goal is to evaluate actuator behavior, sensing repeatability, and long-duration performance for modular robotic systems.

Key Contributions

  • Designed and fabricated a modular platform for repeated actuator testing.
  • Developed CAD components including weight carriages, encoder mounts, linear-bearing supports, actuator fixtures, and modular sensor holders.
  • Integrated AS5600 magnetic encoders, INA260 current sensors, infrared limit sensors, and ESP32-S3 microcontrollers.
  • Developed embedded data acquisition software for logging actuator angle, current, voltage, magnetic field strength, and cycle count.

Methods / System

  • Hardware: twisted-string actuator, payload carriage, encoder fixture, current sensor, limit sensors, ESP32-S3.
  • Sensing: AS5600 magnetic encoder with AGC, magnitude, status, and raw angle monitoring.
  • Software: Arduino-based firmware and host-side data logging for repeated cycle experiments.

Results and Next Steps

  • Current focus: improving encoder repeatability through magnet alignment, air-gap adjustment, and mechanical redesign.
  • Future updates: add actuator lifetime data, payload range, repeatability metrics, and experiment videos.
