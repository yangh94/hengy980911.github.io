Overview

This project developed an autonomous differential-drive mobile robot with embedded control, sensor-based navigation, and real-time telemetry.

Key Contributions

  • Designed and assembled a differential-drive robot based on dual ESP32 microcontrollers.
  • Implemented closed-loop PID velocity control using encoder feedback.
  • Integrated ToF sensors, ultrasonic ranging, and Vive Lighthouse localization.
  • Built a Wi-Fi interface for remote control, online PID tuning, and telemetry visualization.

Methods / System

  • Low-level control: encoder-based velocity regulation.
  • High-level behavior: wall following, obstacle avoidance, and navigation around a test track.
  • Hardware: ESP32, encoder motors, ToF sensors, ultrasonic sensors, Vive sensors, motor driver.

Results and Next Steps

  • Reduced lap completion time by 18% through controller tuning, sensor improvements, and mechanical adjustments.
  • Future updates: add robot videos, control diagrams, and telemetry screenshots.
