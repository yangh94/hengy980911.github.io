# Heng Yang Academic Website V2

This is a static academic portfolio website.

## Local preview

Open `index.html` in your browser.

Do not open `README.md` as the website. This file is only the instruction file.

## Publish with GitHub Pages

1. Create a GitHub repository named:
   `hengy980911.github.io`
2. Upload everything inside this folder:
   - `index.html`
   - `style.css`
   - `assets/`
   - `projects/`
3. Go to the repository Settings.
4. Go to Pages.
5. Choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Wait 1–3 minutes.
7. The site should appear at:
   `https://hengy980911.github.io`

## What to replace later

- Replace the placeholder photo block with your real photo.
- Replace SVG placeholders in `assets/` with real images.
- Replace `assets/CV_HY.pdf` with your newest CV.
- Replace `#` or missing links with GitHub / Google Scholar when ready.

Use these filenames if you want the site to update without changing HTML:

- `assets/tsa.svg` → TSA experiment/CAD image

- `assets/mobile_robot.svg` → mobile robot photo
- `assets/agv.svg` → AGV CAD rendering
